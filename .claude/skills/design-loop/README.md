# Design Loop

Jack Roberts' critic loop, saved exactly as his free guide publishes it
(https://app.notion.com/p/The-Design-Loop-Free-Guide-3b8e8d6bd13781ff8bf2fc06fd5d0aac).
Type `/design-loop` in this repo. It needs a specific reference ("the bar")
it can open and screenshot, a `design-system.md` to judge against (for this
site, CLAUDE.md's visual rules are that document), and a way to render the
output. Installed 2026-09-24.
