Glaido vs Linear

Glaido measured against Linear's design system

Both sites run the same architecture: a dark canvas, one bright accent, a token file, mono eyebrows. The gaps that make Linear read as more finished are measurable, and they concentrate in three areas. Every value below was read from live computed CSS on both sites.

Summary

The three largest gaps

01

Letter spacing is too loose

The 76px headline sits at -0.76px. Linear sets display type at -0.022em, which is -1.67px at that size. Small text runs the opposite way: Glaido adds positive tracking where Linear uses negative.

02

There is no elevation ladder

Pricing cards use #0d0d0d on a #0d0d0d page, so the card reads as a surface only because of its border. Linear steps through three greys before it adds a line.

03

Hero art competes with the product

A full bleed lime gradient sits behind a mocked up Slack window. Linear uses product screenshots as the primary visual and adds no decorative imagery.

Design decisions

Two changes that need a call from you

01

The hero shows a mocked up Slack window

The interface on screen is not Glaido. Linear's visual language is built entirely on real product screenshots, with no stock photography, decorative illustration, or invented interfaces. A real capture of Glaido dictating into an app would carry the hero on its own, and the lime gradient behind it would no longer be needed.

Glaido nowhero art : full bleed lime gradient hero mock : invented Slack window
Change tohero art : gradient floor only hero mock : real Glaido capture
02

Section dividers are doing the job of spacing

All eight sections close with a full width rgba(255,255,255,.1) rule inside a 1336px container, which leaves the page dense and short on rest. Linear separates sections with 96px of space at 1160px and uses no rules at all. Keep one or two rules for genuine chapter breaks, set them to #23252a, and remove the rest.

Glaido nowmax-width: 1336px; section { border-bottom: 1px solid rgba(255,255,255,.1); } x8
Change tomax-width: 1160px; section { padding-block: 96px; } /* rule only at chapter breaks, #23252a */

Token patch

Values to swap in your token file

The architecture stays as it is. These replace values only. Keep the Glaido lime.

/* surfaces: three levels instead of one */
--color-neutral-950: #08090a;   /* canvas, was #0d0d0d */
--color-neutral-900: #0f1011;   /* card, was #1a1a1a   */
--color-neutral-850: #161718;   /* elevated, new       */

/* borders: cool hairlines instead of white */
--color-border-default: #23252a;  /* was rgba(255,255,255,.1) */
--color-border-section: #383b3f;

/* text: pure white is for headings only */
--color-text-default:   #ffffff;  /* h1 and h2 only     */
--color-text-secondary: #d0d6e0;  /* h3, lead copy      */
--color-text-subdued:   #8a8f98;  /* body, was #fff/70  */
--color-text-muted:     #62666d;  /* captions, metadata */

/* radii: five values, each with one job */
--radius-sm: 2px;   --radius-md: 4px;
--radius-lg: 6px;   /* buttons and inputs, was 2px  */
--radius-xl: 12px;  /* all cards, was 8 / 16 / 18   */
--radius-full: 9999px;

/* elevation: hairlines carry it, not shadow */
--shadow-subtle: inset 0 0 0 1px #23252a;
