# Website Intelligence

Jack Roberts' research-then-build pipeline, from his Drive folder
(2026-03-27), installed 2026-09-24. Scrapes a client's site, scores the top
competitors, writes a PDF-ready competitive analysis, stops for approval,
then builds. Needs Firecrawl (falls back to WebFetch) and the open web. The
natural first brief is HelioFlux against the competitor set already tagged
in Magpie.
