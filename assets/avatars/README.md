# Room avatars

Drop one square PNG per seat here and the room shows it in every circle
avatar automatically (initials stay as the fallback):

- `kelly.png`
- `codex.png`
- `claude-code.png`
- `kip.png`
- `vellum.png`

Use 256 x 256 or larger, square, and keep the face or mark centered; the room
crops to a circle. No other files in this folder are served.
