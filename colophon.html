Colophon

The page where a site explains itself. No frameworks and no build step: everything here is HTML, CSS and JavaScript you could read with view source.

Ingredients

Markup
HTML written by hand. Every tag on purpose.
Style
One stylesheet with custom properties. The playground rooms keep the old lab stylesheet.
Motion
A little plain JavaScript and the Web Animations API. The playground still runs on GSAP.
Type
Heliora, survivor of 97 auditions, self-hosted as WOFF2.
Pictures
Plates are screenshots of the live projects. Magpie's plate is redrawn in HTML from the real popup.
Host
Vercel. Every push to main goes straight to the internet.
Memory
Git for time travel. No backup files, no final-final-v2 folders.

House style

Version 1.0, the collection.

  1. The site is a collection.

    Every project gets a plate, a label and a number, like an object in a museum's online catalogue.

  2. Paper, ink, and four backdrops.

    Warm paper and deep ink green. Mint, lilac, sand and sky are the backdrops plates sit on, not decoration.

  3. One typeface.

    Heliora everywhere. Hierarchy comes from size and weight, never from a second font.

  4. One rainbow.

    The Magpie feather is the only saturated color on the page.

  5. Real over cute.

    If it doesn't work, it doesn't go in the index. The fun stuff lives in the playground.

  6. No em dashes, mobile first.

    Ever. And everything is tested at 390 pixels wide.

References

The structure comes from museum collection sites: plates, tombstone labels and an index you can scan. For the feel, I pulled references through Refero: the private-archive warmth of mymind, the ordered calm of Daniël van der Winden's site, and herdi.ng's habit of showing the product inside a frame.

Versions 0.5 to 0.9 were the lab: stacked color slabs, dot tags, draggable stickers and a lot of confetti. The rooms in the playground still wear that look, and the log keeps the receipts.
