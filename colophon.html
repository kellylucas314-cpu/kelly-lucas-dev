colophon

How this
is made.

(a colophon is the page where a site explains itself)

No frameworks, no build step, no secrets. Everything here is plain HTML, CSS, and JavaScript you could read with view source.

the stack

Ingredients

  • Markup HTML written by hand. Every tag on purpose.
  • Style One CSS file. Custom properties, stacked color slabs, 28px corners.
  • Motion GSAP from a CDN: ScrollTrigger, Draggable, and a hand-rolled confetti cannon.
  • Type Heliora, survivor of 97 auditions. Hosted right here, no font CDN.
  • Host Vercel. Every push to main goes straight to the internet.
  • Memory Git for time travel. No backup files, no final-final-v2 folders.
lab rules

House style

  • Rule 01 Warm off-white page. Mint, cream, and lilac slabs.
  • Rule 02 Every block gets a dot tag in the corner.
  • Rule 03 Headlines huge and tight. Copy lowercase-leaning.
  • Rule 04 No em dashes. Ever. Ask the footer why.
  • Rule 05 Mobile first. Everything tested at 390 pixels wide.
  • Rule 06 Charming beats slick. Honest beats finished.
