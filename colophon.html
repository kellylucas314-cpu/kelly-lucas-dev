Colophon

The page where a site explains itself. No frameworks and no build step: everything here is HTML, CSS and JavaScript you could read with view source.

Ingredients

Markup
HTML written by hand. Every tag on purpose.
Style
One stylesheet with custom properties. The playground rooms keep the old lab stylesheet.
Motion
A little plain JavaScript and the Web Animations API. The playground still runs on GSAP.
Type
Lato, the same face Heliopolis uses, self-hosted as WOFF2 in four weights.
Drawings
Made in my Heliopolis style with an image model, then recolored into this site’s six colors. Each file keeps its prompt next to it.
Pictures
Room pictures are screenshots of the real rooms. Magpie’s popup is redrawn in HTML from the real one.
Host
Vercel. Every push to main goes straight to the internet.
Memory
Git for time travel. No backup files, no final-final-v2 folders.

House style

Version 1.0.

  1. Drawings lead.

    Every page opens with one drawing, never boxed in or cropped, with paper all around it.

  2. Six colors.

    Paper and navy do the work. Pale teal and pale coral fill the drawings; teal and coral are small accents. Navy carries every word.

  3. One typeface.

    Lato everywhere: light for the big words, regular for reading.

  4. A fine pen.

    Hairline navy rules between things, flat fills, and no shadows anywhere.

  5. Real over cute.

    If it doesn’t work, it isn’t in the projects. The fun stuff lives in the playground.

  6. No em dashes, mobile first.

    Ever. And everything is tested at 390 pixels wide.

References

The look comes from Heliopolis, the team space I designed for HelioFlux: warm paper, a fine navy pen, and one drawing per view. This site keeps the pen and gets its own colors, which started as a Huemint palette and were tuned until navy could carry all the text.

Versions 0.5 to 0.9 were the lab: stacked color slabs, dot tags, draggable stickers and a lot of confetti. The rooms in the playground still wear that look, and the log keeps the receipts.
