kellylucas.dev measured against Isomorphic Labs

The lab already runs the Isomorphic architecture: pale fields, near black hairlines, uppercase tags, big quiet whitespace. The difference is discipline, and it lives in four places: display tracking, the number of hairline values, the number of type sizes, and how a card lifts on hover. None of it is a redesign.

1 · Letter spacing

The biggest headline is the loosest one

The hero h1 renders at 151px with -0.005em, which is -0.76px. Every other display size on the page tracks at -0.035em to -0.040em, and CLAUDE.md asks for -0.04em. Isomorphic sets its largest display at -1.7px on 56px, which is -0.030em. The one headline people see first is the only one not following the site's own rule.

2 · Hairlines

Eight border values doing two jobs

The homepage draws hairlines at full ink and at alphas of 0.10, 0.12, 0.18, 0.25 and 0.35, plus two more in the tail. Isomorphic uses exactly two: 1px #1E1E1E for structure and 1px #D8D8D8 for everything soft. The eye reads six near identical greys as slightly wrong rather than as a system.

3 · Type scale

Fifteen sizes where nine would do

The homepage renders 10, 12, 13, 14, 15, 16, 17, 28, 32, 38, 56, 79, 108, 151 and one more. Six of those sit between 12 and 17 pixels. Isomorphic runs seven desktop roles. The notebook page on the golden ratio is the fix: 1.27 steps from 11px land on 11, 13, 17, 22, 28, 36, 45, 56, then the display clamps. Nine steps, each with a job.

4 · Border radius

Five radii. Hold the line.

The homepage ships five: the pill, the 1.5px dot, the 28px slab, the 4px mark and the 14px media frame. Isomorphic ships five too. This is the one dimension where the lab already has the discipline, so the job is to keep new pages from adding a sixth. The design desk added 9px and 6px today before this probe caught it; both are gone.

5 · Elevation

Cards hover with a shadow the system never uses

At rest the homepage is honest: the only shadows are the stickers' 2px paper edge and one media frame. On hover, every experiment card lifts 6px with a 0 16px 32px shadow. Isomorphic has no shadow anywhere. Agent Commons already wrote the rule down: outline, never elevation. This one is a taste call, so it is in the second list.

6 · Accent

Zero accent uses above the fold

The probe found no chromatic accent on the homepage at all: mint, cream and lilac are all under 20% saturation. Isomorphic keeps one technical blue and spends it only on focus and utility. The HANDOFF file has carried "one sharp accent color" as an open decision since May. The measurement agrees with the note.

The patch

The mechanical half, as CSS

/* hairlines: two values instead of eight */
:root {
  --line-strong: #14201a;
  --line: rgba(20, 32, 26, 0.14);
}

/* display: the h1 follows the same rule as the h2 */
.display { letter-spacing: -0.03em; }

/* type: nine steps at 1.27, from the notebook */
:root {
  --t-1: 11px;   /* tags */
  --t-2: 13px;   /* labels, scribbles */
  --t-3: 17px;   /* body */
  --t-4: 22px;   /* lede small */
  --t-5: 28px;   /* card titles, now-body */
  --t-6: 36px;   /* lede */
  --t-7: 45px;   /* quote */
  --t-8: 56px;   /* display floor */
  /* display: clamp(56px, 10.5vw, 168px) stays */
}

/* radii: the five that exist, written down */
:root {
  --radius-block: 28px;  --radius-card: 20px;
  --radius-media: 14px;  --radius-mark: 4px;
  /* pill: 999px. nothing else. */
}
