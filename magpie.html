My web clipper and private library. It collects shiny things from the web and drops them into two nests at once: a full note in my Obsidian vault, and a card in a gallery I can search.

The path of one clip

From the feather to the right shelf, without me filing anything.

  1. Clip

    I press the feather, or Alt+Shift+M. The popup already knows what the page is (a web page, a video with a transcript, a paper with its PDF), shows a preview, and takes my tags and a note. If I select text first, only the selection is saved.

  2. Two nests

    A small server on my Mac writes a Markdown note into the vault, with my notes, a page summary, the content and any transcript, and adds an entry to the library. Clipping a page twice updates it instead of making a copy. If the server is asleep, the clip downloads as a Markdown file, so nothing is lost.

  3. Find it again

    The gallery searches titles, notes, sites and tags, filters by type and origin, and opens every note in a reader. The galaxy map draws the whole library as clusters of stars: drag to fly, tap a star to open it.

  4. Put it to work

    Design clips sort themselves onto the design desk. One set of rules decides where a clip lands, and the popup shows its guess before I save: a desk tag wins, then my own sites, then project tags, then resource or example.

It knows what it's looking at

Every clip gets an honest label and the right kind of keepsake.

Pages

The preview comes from the page's own image, then from a screenshot taken at clip time, then a plain title card.

Videos

YouTube clips bring their transcript along, read from the browser with yt-dlp as the fallback.

Papers

The open-access PDF and a searchable text copy. When no free PDF exists, it says abstract only. It never goes around a paywall.

Repos

GitHub repositories are labeled as repos, not web pages, so they file with the tools.

The bulk workbench

For the days I have forty tabs and a camera roll of screenshots.

Drop the whole pile.

  1. Gather

    Paste a messy list or drop screenshots. Text recognition runs on my Mac with Apple Vision, so nothing leaves the machine.

  2. Review

    Magpie finds the links, cleans them up, skips duplicates, unchecks anything already saved, and asks what the pile is for.

  3. Clip

    Each link is clipped in a background tab with the labels I picked. It ends with a cheerful YAY, done.

Built for one

Magpie is a personal tool.

It isn't something you can install, and the library stays behind a password. The design half of it is public, though: everything Magpie files for the design desk shows up there.
