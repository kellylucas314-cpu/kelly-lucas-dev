Magpie clip, read & resurface

A small collection for things worth keeping: save a link, read it, mark the passage that mattered, and meet a few of those passages again later.

Clip → highlight → revisit

  1. 1 Clip something. Choose Add a clip and paste a fictional link such as paper-kettle.example/the-long-middle, then write the note you'd want to read in six months.
  2. 2 Read it. Open Read on any card. Select a sentence and choose Highlight selection — or use Mark a passage on a paragraph if you'd rather not drag.
  3. 3 Annotate and find it. Add a note and tags to the highlight, then search for a word from either — the search covers titles, body text, highlights and highlight notes.
  4. 4 Meet it again. Today offers up to five highlights, the same five all day. Keep rests one for a fortnight, Later brings it back tomorrow, Hide retires it.

Keyboard: / jumps to search, N starts a new clip, ↑↓ move through cards, Enter opens one, Esc closes a dialog. L / T / H switch between Library, Today and Highlights.

Magpie clip, read & resurface — a local fictional demo built for portfolio review. Documents and highlights are stored only in this browser profile. There is no server, no sign-in and no sync, and the demo never leaves the page.

The reading text, the people and the publications are invented for this prototype. Resurfacing here is a simple date-seeded rota, not a memory model — scheduling is still an open research question.
